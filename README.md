# N-Player TV

Lightweight, hardware-accelerated media viewer and TV guide application designed for Android TV and Google TV devices.

## Features
- 10-foot TV UI designed for D-Pad remote control
- High-definition live stream playback with adaptive buffering
- Built-in Program Guide (EPG)
- Quick channel switching and numeric keypad input

## Building
Build with Gradle:
```bash
./gradlew assembleDebug
```
Generated APK will be located at:
`app/build/outputs/apk/debug/app-debug.apk`
